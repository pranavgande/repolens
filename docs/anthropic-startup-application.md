# Anthropic Startup Program — Repolens

Use this draft only with information that is true at the time of submission.

## What are you building?

Repolens is an early-stage developer tool that helps engineers understand unfamiliar GitHub repositories faster. It analyzes repository structure and important source files and turns that evidence into structured technical explanations covering architecture, entry points, execution flow, dependencies, and critical files.

## Why Claude?

Claude is a natural fit for codebase understanding because the product needs to synthesize technical information across multiple files while preserving relationships between components. Claude is intended to be a core reasoning component rather than a generic chatbot layered on top of the product.

## Who is it for?

- Developers joining unfamiliar projects
- Engineering teams onboarding contributors
- Developers working with large or poorly documented repositories
- Teams that need faster technical orientation before making changes

## Near-term roadmap

1. GitHub repository ingestion
2. Claude-powered repository analysis
3. Dependency graph visualization
4. Request/execution-flow tracing
5. Change-impact analysis
6. Team workspaces
7. Evaluation benchmarks for codebase-understanding quality
